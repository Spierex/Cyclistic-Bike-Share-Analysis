# Data

The original Cyclistic dataset consists of a large collection of historical CSV files containing bike-share trip data.

The raw dataset is not included in this repository because of its size.

The dataset contains information such as:

- Ride ID
- Bike type
- Start and end timestamps
- Start and end stations
- Start and end coordinates
- Rider type (member/casual)

The data was consolidated using Python/pandas before being loaded into PostgreSQL for cleaning and analysis.

The final analysis focuses primarily on data from **2024 onwards**.

The project is based on the Cyclistic case study from the Google Data Analytics Professional Certificate.
